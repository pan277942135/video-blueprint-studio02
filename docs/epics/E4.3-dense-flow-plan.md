# E4.3 — Dense Flow / Global Image-Space Motion Evidence

## Scope

E4.3 extracts global frame-to-frame dense optical flow from the normalized analysis video. It is source-level motion evidence intended to support later camera-motion estimation and motion decomposition.

Pipeline slice:

`POINT_TRACKS / DENSE_FLOW -> CAMERA_MOTION`

E4.3 does **not** infer identity, biometrics, demographics, emotion, body-local surface motion, or cross-video correspondence.

## Backend

Use the repository's existing OpenCV runtime only:

- Farneback dense optical flow (`calcOpticalFlowFarneback`);
- no model weights, network download, or fallback model;
- frames are optionally downsampled to a bounded analysis grid while preserving aspect ratio;
- emitted vectors are rescaled back to source-pixel displacement units;
- hard shot boundaries invalidate the cross-boundary flow sample;
- first-frame and shot-start flow are explicit NaN with `valid_frame=false`;
- no temporal interpolation.

## Manifest contract

E4.3 is emitted under `extensions.e4_dense_flow`. It must remain separate from canonical/body-local `surface_motion` because this stage represents raw global image-space evidence.

One source-level NPZ sidecar is emitted:

`artifacts/timeseries/source_dense_flow.npz`

Arrays:

- `flow_xy`: float32 `[frame, grid_y, grid_x, 2]`, previous-frame to current-frame displacement in source pixels;
- `valid_frame`: bool `[frame]`, false for frame 0 and every hard-shot start.

The TimeSeriesRef records source dimensions, grid dimensions, grid-to-source scale factors, checksum, algorithm, config hash, shot-reset semantics, and no-interpolation policy.

## Default configuration

- `max_side_px=320`
- `pyr_scale=0.5`
- `levels=3`
- `winsize=15`
- `iterations=3`
- `poly_n=5`
- `poly_sigma=1.2`
- `flags=0`

Runtime activation is explicit through `VBS_E4_DENSE_FLOW_ENABLED=true`.

## Gates

E4.3 is PASS only when all of the following hold:

1. deterministic textured translation produces non-zero flow and recovers the expected displacement within tolerance;
2. hard shot boundaries emit NaN flow and `valid_frame=false` across the cut;
3. NPZ shape, dtype, companion-array shape and full-timeline semantics match the manifest;
4. every emitted URI resolves to a physical artifact and checksum;
5. no temporal interpolation occurs;
6. BlueprintValidator enforces E4.3 extension/ref integrity;
7. standard CI, Ruff and mypy pass;
8. real-media certification demonstrates physical dense-flow evidence with no new model weights or privacy-boundary changes.

Merging the final PR into `main` remains a project-owner approval gate.
