# Epic E3.1 — 2D Human Pose

## Scope

E3.1 adds per-frame top-down 2D human pose estimation for anonymous E2.2 person tracks. It does not add face landmarks, hand landmarks, identity inference, biometric embeddings, 3D pose, masks, or surface-motion analysis.

## Runtime contract

- Input: normalized CFR analysis video plus E2.2 anonymous person bounding boxes.
- Pose model: local, explicitly approved MMPose checkpoint/config only; no runtime download and no fallback model substitution.
- Output per character: COCO-17 2D keypoints and per-keypoint confidence as dense bundle sidecars.
- Coordinate space: source-frame `pixel_xy` aligned exactly to the normalized CFR frame index.
- Missing/low-confidence frames: represented explicitly (NaN coordinates + confidence 0) rather than hallucinated interpolation.
- Privacy: anonymous track IDs only; no identity inference or biometric embedding export.
- Provenance: model/config/checkpoint hashes, version, license record, config hash.

## Gate

1. Unit tests for result parsing, bbox-to-pose association, dense tensor construction, missing-frame behavior, and schema references.
2. Schema-valid integration test using an injected deterministic pose backend.
3. Standard CI remains green with pose disabled unless a complete approved model configuration is supplied.
4. Separate real-checkpoint certification must pass before E3.1 is marked runtime-certified.
