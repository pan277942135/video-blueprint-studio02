# Epic E3.1 — 2D Human Pose

## Scope

E3.1 adds per-frame top-down COCO-17 2D human pose estimation for anonymous E2.2 person tracks. COCO-17 includes its standard five coarse head keypoints (`nose`, `left_eye`, `right_eye`, `left_ear`, `right_ear`) as part of the body-pose skeleton. E3.1 does not add a dedicated face-landmark/face-mesh model, hand landmarks, face recognition, identity inference, biometric embeddings, 3D pose, masks, or surface-motion analysis.

## Runtime contract

- Input: normalized CFR analysis video plus E2.2 anonymous person bounding boxes.
- Pose model: local, explicitly approved MMPose checkpoint/config only; no runtime download and no fallback model substitution.
- Output per character: COCO-17 2D keypoints and per-keypoint confidence as dense bundle sidecars, including only the five coarse head points defined by COCO-17 and no separate face-landmark output.
- Coordinate space: source-frame `pixel_xy` aligned exactly to the normalized CFR frame index.
- Missing/low-confidence frames: represented explicitly (NaN coordinates + confidence 0) rather than hallucinated interpolation.
- Privacy: anonymous track IDs only; no face recognition, identity inference, or biometric embedding export.
- Provenance: model/config/checkpoint hashes, version, license record, config hash.
