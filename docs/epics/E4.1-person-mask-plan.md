# E4.1 — Anonymous Person Mask

## Goal
Add trustworthy per-frame binary foreground masks for existing anonymous E2.2 character tracks.

## Contract
`Character.person_mask_ref` already exists and remains nullable. Enabled output must use `rle_json`, `bool`, shape `[frame, height, width]`, axes `[frame, y, x]`, unit `binary`, coordinate space `pixel_xy`, per-frame sampling, and no interpolation.

Missing track frames are explicit `null`. A character with zero valid mask observations keeps `person_mask_ref = null` and no orphan sidecar is written. Rectangle/bbox rasterization must never be presented as segmentation output.

RLE metadata: `row_major_binary_rle_v1`, foreground `1`, background `0`, missing frame `null`.

## Quality
Coverage is valid mask frames divided by track-present frames. Confidence must be measured by the backend; never fabricate a score.

## Runtime gate
Preferred candidate is official OpenMMLab `rtmdet-ins_tiny_8xb32-300e_coco`. Before inference, pin official config and checkpoint, compute full SHA256, record runtime/license evidence, require local fail-closed configuration, and run dedicated real-runtime certification. Hash bootstrap may run before inference approval.

## Regression gate
Semantic validator tests, deterministic injected-backend tests, standard CI, E2 RTMDet, E3.1 RTMPose, E3.2 MediaPipe, and E4.1 certification must pass before merge. Merge to `main` remains an explicit high-risk authorization point.

## Out of scope
Point tracks, dense flow, camera motion, body-local frame, surface motion, micro-motion, environment analysis, and identity inference.
