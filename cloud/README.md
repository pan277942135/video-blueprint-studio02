# Cloud usage

## Cloud Shell / browser editor

1. Upload or clone this project.
2. Open a terminal in the project root.
3. Install E0 Python dependencies if needed.
4. Run `bash scripts/e0_preflight.sh`.
5. Start Gemini in the project root.
6. Run `/vbs:e0`.

## Cloud Workstations

Use the same repository root and keep `GEMINI.md` at the root so project-level context is loaded.

GPU should remain disabled for E0. Add GPU capacity only when real CV inference begins in later Epics.
